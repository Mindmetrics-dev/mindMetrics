# Assets a exportar desde Figma

Coloca cada archivo en `Frontend/static/img/` con el nombre exacto indicado.

| Archivo | Descripción | Formato | Tamaño sugerido |
|---|---|---|---|
| `logo-mindmetrics.png` | Logo completo "MindMetrics" (texto + ícono cerebro) | SVG | ancho ~220px |
| `logo.png` | Solo ícono del cerebro azul (para navbar) | SVG | 40x40 |
| `logo.png` | Ícono cerebro en blanco (va dentro de botones primarios) | SVG | 24x24 |
| `FondoRegistro.png` | Fondo de las pantallas de autenticación (cabeza con cerebro de circuitos) | JPG @1x | 1920x1080 |
| `coffee.png` | Ilustración de la taza de café (recomendación dashboard) | PNG transparente | 200x200 |
| `logo.png` | Favicon del navegador | PNG | 32x32 |

**Íconos genéricos (FASE 2/3):** Para íconos de navegación, controles del calendario,
flechas, etc., usaremos Lucide via CDN inline en lugar de SVG individuales.
Se cargará desde `https://unpkg.com/lucide@latest` cuando aplique.
